# 🧠 Ultimate Quiz Master

A modern desktop Quiz Application built using **Python** and **CustomTkinter** featuring an interactive GUI, leaderboard, achievements, XP system, timer, and SQLite database.

---

## ✨ Features

- 🎮 Modern GUI
- 👤 Username Login
- 📚 Multiple Categories
- 🧠 Random Questions
- ⏱ Countdown Timer
- 📈 Progress Bar
- 💯 Score Calculation
- ⭐ XP System
- 🏆 Level System
- 🪙 Coins
- 🥇 Achievements
- 📊 Leaderboard
- 💾 SQLite Database
- 📜 Quiz History
- 🎨 Dark Theme
- 📂 JSON Question Bank
